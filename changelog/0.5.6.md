# 0.5.6 — 2026-11-28

Vercel deployment, a Promotions view, Google Takeout imports, deliverability tools, masked aliases, and a large round of security and bug fixes. Apply the new database migrations from Admin settings after updating.

## Security

- Cookie-authenticated changes and realtime upgrades refuse cross-origin requests, and password reset links no longer take their origin from the `Host` header.
- Wrong second-factor codes are limited per account, and each TOTP code works only once.
- Changing the recovery or forwarding email, forwarding rules to outside addresses and new webhook URLs require fresh proof of identity.
- Other users' drafts stay private in shared mailboxes, on every read and write route and over JMAP.
- JMAP: moving or deleting mail needs full access; folder changes are scoped to the permitted mailbox; upload ids are validated.
- Crafted address headers, invite organizers, HTML and request bodies can no longer stall or overload inbound processing (postal-mime upgraded).
- Tighter checks on IPv6 private addresses, thread participants, shared-mailbox contacts, alias creation, imports and scheduled send cancellation; the license key is no longer logged; a moved primary admin role revokes the old API keys.

## Added

- Deploy to Vercel, with Vercel Blob, S3 or Backblaze B2 storage and Vercel Queues; see `docs/vercel.md`.
- Promotions view, per-sender choices and a Subscriptions page, off until turned on per mailbox (#372, #379).
- One rule to move newsletters and promotions to a folder, Spam or Trash (#369).
- Import Google Calendar, Contacts and Drive from Google Takeout (#381, #382, #384).
- DMARC aggregate reports with alerts, MTA-STS policy hosting and TLS-RPT reports, off by default (#380, #383).
- Bounce and complaint suppression list, off by default (#376).
- Masked email aliases with labels, on/off switch and send-as (#278).
- Calendar invitations: auto-add, reminders, attendees, more recurrence rules, per-occurrence changes, counter-proposals and a note with your answer (#332); answer invitations with an API key (#334).
- Per-protocol app passwords (#373), and a first step towards CalDAV/CardDAV behind an admin switch. It answers discovery only; calendars and contacts do not sync yet (#377, #385).
- Automatic updates, following new releases or every change (#302).
- Undo for message actions (#310), hover actions in mail lists (#308) and a refresh button (#307).
- Spam strictness levels, domain blocking and a cold-outreach signal (#367).
- Resend-compatible APIs through `RESEND_BASE_URL` (#306).
- Prebuilt multi-arch Docker images on GHCR (#365).

## Improved

- Attachment limit can be raised to 50 MB on Node/Docker; files a provider cannot carry go out as download links, with an editable message (#370).
- Onboarding asks for your name; without Cloudflare credentials the DNS records are listed to set by hand.
- The DNS warning follows saved DNS checks and can be rechecked.
- Installed app: better icons, safe areas on iOS and an offline page (#368).
- Authentication passes count for less in spam scoring for first-time senders (#371).
- Accessibility fixes for navigation, rule rows, dialogs and contrast (#363).
- Toasts show at the bottom left; the JMAP state query is faster (#327).

## Fixed

- Inbound mail is held, not lost, while database migrations are pending (#374), and kept when forwarding it fails (#338).
- Forwarding reaches every destination through the email relay (#343); the SMTP listener marks forwarded mail and refuses rejected recipients early (#342, #352).
- JMAP: sorting, paging past 10,000 messages, negated and thread filters, empty filters and session discovery (#318, #347–#350, #366).
- Imports: IMAP reply matching, folder names, refused connections and large folder checks; mbox export round-trips `From` lines (#315–#317, #324, #346, #355, #357).
- Calendar reminders, booking, invite text and month-end events (#325, #345, #359).
- Composer attachments, template saving, shortcuts, permanent-delete confirmation and empty signature drafts (#329, #360).
- Search, unsubscribe, threading and cleanup fixes; list lookups stay within D1's parameter limit (#305, #339, #361, #375).
- Domain setup, login, password reset and Resend MX detection (#322, #323, #328, #337).
- Errors are shown when rule, import, folder and webhook actions fail, and disabled webhooks stop retrying (#321, #353, #364).
