# 0.4.1 — 2026-10-03

## Added

- Multiple accounts, with alias selection when creating accounts.
- Dark mode with a light/dark/system theme setting.
- Bookings.
- Calendar tools for agents.
- HTML signatures.
- Show the recipient address, with an optional full form.

## Improved

- Bulk message actions, permissions, navigation and menu UI.
- Attachments, original-message view, backup UI.
- Mobile layout: icon-rail sidebar, narrow-screen wrapping.
- Calendar background; calendar drag performance.

## Performance

- Bounded conversation queries for message lists.
- Faster message list and folder counts on large mailboxes.

## Fixed

- Routing: accept a blank forwarding address on deliver and reject rules.
- Page every conversation; drop host sqlite knobs.
- Backups: skip `jmap_mailbox_revisions` as derived data.

## Security

- Ran a security audit.
