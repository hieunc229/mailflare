# 0.5.1 — 2026-10-10

## Added

- **Localization**: interface languages Spanish, French, German, Russian, Simplified Chinese, Japanese, Indonesian, Turkish, Vietnamese, Hindi, Arabic, Bengali, Urdu and Brazilian Portuguese; plurals, RTL support, server translator and on-demand locale catalogs. Nearly every screen translated. Language and time zone moved to account settings.
- **Drive**.
- **Storage**: AWS S3 and Backblaze B2 as object storage.
- **PWA** and Web Push notifications.
- Scheduled tab (#97).
- Auto-delete Trash and Spam after a chosen number of days; permanent delete from Trash and Spam.
- Import whole IMAP folders in batches.
- IAM policy shown when an SES save is refused for missing permissions (#98).

## Improved

- Email style preservation with isolated rendering and remote content controls.
- Drafts view on mobile; Drive layout.

## Fixed

- Read status inconsistency.
- App passwords now send `mailboxIds` so JMAP keys can be created.
- Workaround for a Cloudflare 401 error.
- Recipient-display test bundling; email paint contained in the reader.

## Docs

- README language docs and domain configuration guide.
