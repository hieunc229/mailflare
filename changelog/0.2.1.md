# 0.2.1 — 2026-09-18

A large release: threading, routing, JMAP, search, security and self-hosting.

## Added

- **Mail**: conversation threading and conversation view, Cc/Bcc and reply-all, forwarding with attachments, rich-text composer with delete button.
- **Shared inbox**, forwarding, snooze and per-message actions; inboxes spanning multiple domains.
- **Aliases**: arbitrary email aliases, subaddressing (plus and dot), alias priority over the "all domain" option, concurrent alias creation handling.
- **Routing**: catch-all, forwarding and reject rules with priorities; routing scopes; routing page in admin.
- **Webhooks**: management UI and delivery retry visibility.
- **Search**: full-text search with Gmail-style operators on an FTS5 index.
- **Auth**: password reset by recovery email and TOTP two-factor authentication.
- **JMAP**: server for external mail clients, `Email/import` for MIME-composing clients and the `header` query filter.
- **Self-host**: run Mailflare as a Docker container on any host.
- **Keyboard**: shortcuts and Command Palette (Cmd+K).
- Spam filter, signature and auto reply, sending switch per domain, mailbox deletion in settings.
- Avatars in the email view and improved contact profile.
- Import from file/IMAP, improved backup/export, `Add sequenzy`.

## Fixed

- Domains: roll back only the Cloudflare config a failed setup created; skip the Worker catch-all on Node/Docker; skip the sending API for receive-only domains; delete MX if already present during setup.
- Backups: include `mailbox_aliases` and tables added since the format shipped.
- Mailboxes: each personal mailbox gets its own name and avatar.
- Setup: sync fresh D1 bootstrap schema with migrations 0013/0021/0022.
- Sidebar crash on non-JSON responses, nav key warning, admin nav entries.
- Dependencies: resolved all `npm audit` vulnerabilities, lint script fixed.

## Changed

- Replaced the update workflow with a cron.
- Added an index on `api_keys.prefix` for fast key lookups.
- Migrations now run as part of the build script.

## Docs

- Added `CLAUDE.md`, roadmap, routing rules and webhook docs, deployment guide updates, funding file, license update.
