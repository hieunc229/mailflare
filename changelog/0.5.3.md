# 0.5.3 — 2026-10-28

## Added

- **Databases**: PostgreSQL, MySQL and libSQL alongside D1.
- **Imports** run as background jobs with progress; read/spam inferred from headers; Google Takeout import (#184).
- **Opt-in read receipts** with per-domain pixel hosts (#181), configurable default.
- **Follow-up reminders** for sent mail without a reply.
- Undo-send window as an account setting.
- **Spam**: trust SES/Resend verdicts, blocklist, domain-age and impersonation checks (#180).
- **Mobile**: JMAP change log, device sign-in (QR), native push relay (#154); unread count as PWA badge (#160).
- Account deletion (#100); users manage their own mailboxes from Settings (#133).
- Assistant gets the open email as context (#140); MCP scheduled tools and atomic scheduled-send cancel (#128).
- Sinhala interface language (#110); missing translations filled in all locales; Turkish fixes (#123, #130).
- Skip configuration when adding a domain (#152); `.env.docker.example` (#139).

## Performance

- Covering and foreign-key indexes for folder listing, counts and conversation paging.
- Scan-first conversation paging; fewer round-trips for dashboard, JMAP reads and sending (#188).
- Deduplicated requests and bounded client caches (#149).
- Opt-in pragma tuning; sqlite mmap/cache settings for self-hosting.

## Fixed

- Inbound: stored raw keyed on a content hash; relay retries are idempotent.
- Login rate limits keyed by real client IP behind proxies; client IP resolved at the socket.
- Domain routing restricted to authorized admins (#147).
- Proxy consented remote email images on Workers (#148).
- MX conflict is confirmed and retried when adding a domain.
- Conversation unread state and counts (#135); draft attachments, duplicate drafts and past send times (#134).
- Reply goes to the Reply-To address (#122); own-alias senders kept as manual recipients (#145).
- JMAP: RFC 6901 pointer unescaping (#162), batched id lookups (#157), unknown IETF capabilities ignored (#155).
- Shortcuts no longer fire on Cmd/Ctrl/Alt combos (#161).
- Import: IMAP CPU limit and read state (#179); kept messages when contact update fails (#183).
- Backups list drive and web-push tables (#168).
- Autosave no longer invalidates AI draft review; Workers AI streams no longer repeat text (#120); insert-link popup no longer submits the form (#141).
- Password reset email sent in the user's language (#136).
- Self-hosted update guidance (#107).

## Changed

- Migrated to Vite+ (#121).
- Second round of accessibility fixes (#131); routing rule controls named (#129).
- Every schema change now requires migrations for all dialects.
