# 0.5.4 — 2026-10-30

Security hardening release (inbound mail, email rendering, webhooks, AI/MCP automation).

## Security

- **Inbound** (#214–#217, #219): bounded text-line floods and preflighted every `parseRawMime` caller; capped stored inbound fields without splitting surrogate pairs; orphaned raw MIME deleted and swept daily.
- **SMTP** (#215): hardened self-hosted ingress, verifies SPF/DKIM/DMARC, refuses unknown recipient domains, counts only admitted sessions against limits.
- **Authentication** (#216): spam engine enforces auth policy; a header-forged pass can no longer hide a real failure.
- **Email rendering** (#220, #221): compose link XSS and frameset crash fixed; popover and command invoker attributes forbidden; no-referrer on area links; `unsafe-eval` dropped from the production CSP and COOP added; remote content defaults to ask; image proxy rejects wildcard-DNS and private hosts, resolve-checks, rate limits and runs on Node; remote fonts dropped; no Gravatar lookup for spam/trash senders.
- **Attachments and files** (#218, #222): dangerous attachments flagged and download gated; filenames and `Content-Disposition` hardened and capped; shared-file links tied to message state; downloads served as octet-stream.
- **Threading and contacts** (#223): forged `In-Reply-To`/`Message-ID` can't inject into threads; inbound mail can't rename contacts, forge read state or notify from trash; push notifications show the real sender address; the forwarded loop-guard marker is signed.
- **Webhooks and providers** (#224): targets constrained and hosts resolved, private addresses refused; spam/trash dispatch skipped; SNS signatures verified with replay rejection; relay header map signed with a timestamp; Resend header map bounded; RDAP and URLhaus kept to public https hosts.
- **AI / MCP** (#225): automation constrained against injected mail; in-app approval for assistant calendar edits and deletes; send review flags AI origin and unfamiliar recipients; MCP results marked untrusted and tool calls audited.
