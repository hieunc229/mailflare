# 0.5.5 — 2026-11-14

Calendar, contacts and conversation features, faster mail handling, and a UI polish pass.

## Added

- Contacts address book (#298).
- Calendar: month view that remembers the chosen view (#246), subscribe from Google, Outlook or a phone (#247), and accept, decline and track invitations (#248); invites in messages render with their details.
- Booking: guests get a confirmation email with a calendar file, customizable per event (#297).
- Notes on each conversation (#237).
- Save attachments to Drive and download all as a ZIP (#269).
- Dismissible mailing-list notice with inline unsubscribe on open messages (#279); one-click and `mailto` unsubscribe, plus unsubscribe and delete all (#243).
- Passkey sign-in and secure sign-in policies (#231).
- Per-user Calendar and Drive visibility (#242).
- Anthropic as an assistant provider (#287).
- Auto-advance to the next email after archive or delete (#286).
- Signed-in visitors are redirected from the home page to the inbox (splash screen shows once).
- Security policy with private vulnerability reporting (#289).

## Improved

- Performance: folder switching and message opening are near-instant (#256), fixed waits and per-row work removed (#258), the landing account shows immediately (#262), and inbound mail is processed without waiting for a batch to fill (#288).
- Fetch reads are served through a D1 session so read replicas are used (#268).
- API keys verify with SHA-256 to fit the Workers free-tier CPU limit (#245).
- Native selects and browser dialogs replaced by Radix-based components (#291); calendar, email and message UI alignment; add-mailbox modal.
- Scheduled sends can be rescheduled (#235).

## Fixed

- Inbound mail is deferred on failure instead of bounced (#281).
- Caret stays in place while typing in the rich text editor (#267).
- Per-message sender names kept in notifications (#266).
- Mailbox managers see their own domains and can create accounts on them (#285, #255).
- JMAP state query stays within D1's compound SELECT limit (#283).
- Resend's published records accepted in domain health checks (#241); `queryDns` reports only the requested record type (#249).
- Display names with escaped quotes or backslashes parse correctly (#250).
- OpenAI assistant requests work with modern GPT models (#251).
- Modal backdrops no longer lighten the dark theme (#261); mobile message actions fit inline (#260).
- First-run domain setup works without Cloudflare when DNS is skipped (#295).
- Admin layout crash from `useMailSearch` (#277).
- Lint, type-check and test suites green again (#282, #284, #292).
