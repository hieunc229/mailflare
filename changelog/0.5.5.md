# 0.5.5 — 2026-10-31

MCP clients can organize mail the way the dashboard does.

## Added

- **MCP**: `list_folders`, `star_email`, `snooze_email`, `move_to_folder` and `search_contacts`, scoped to the key's mailboxes and permissions. `search_contacts` returns only people with mail in those mailboxes.
- **MCP**: `list_emails` and `search_emails` take the `starred` and `snoozed` folders or a custom folder's `folderId`.

## Fixed

- MCP `move_email` to Inbox takes the message out of its custom folder and snooze, so it shows in Inbox.
- MCP and assistant inbox listings leave out snoozed mail.
- The MCP server reports the Mailflare version, and every mail tool call is audited.
- Translations for the attachment warning, forwarding rules, assistant calendar review, send review notices and import resume strings in all 33 languages; removed catalog keys the app no longer uses.
